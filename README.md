# Warioland-4-Rumble-label
![wl4-rumble-label-github](https://github.com/user-attachments/assets/4e902049-424c-491c-b535-07f4d76f6b73)

A label to use with djeddit's Jungle Rumble! patch for Warioland 4: https://github.com/djedditt/wl4-rumble.

For personal and educational use only.

The PDF can be printed directly, it is set at the correct size to fit a GBA cartridge shell. If you have it printed by a shop, make sure they cut following the pink shape.

The SVG file was built using Inkscape and can be modified as you see fit, notably the green color overlay on the background can be tweaked to more closely match the original.

SVG layers (from top to bottom):
| Layer  | Description |
| ------------- | ------------- |
| **Outline**  | is the shape of a GBA cartridge label, to be used as a guide and not to be printed  |
| **Rumble**  | RUMBLE text drawn using the following font: <a href="https://www.vecteezy.com/vector-art/445592-font-design-for-world-rock-climbing">Rock Climbing Vectors by Vecteezy</a>  |
| **Text**  | contains the TM and AGB-AWAP-EUR texts  |
| **Nintendo**  | has the vector Nintendo logo taken from [Wikipedia](https://en.wikipedia.org/wiki/File:Nintendo_red_logo.svg)  |
| **Original Seal**  | vector image from [Wikipedia](https://en.wikipedia.org/wiki/File:Original_Nintendo_Seal_of_Quality_emblem.svg)  |
| **CE**  | marking using an edited version from [Wikipedia](https://en.m.wikipedia.org/wiki/File:Conformit%C3%A9_Europ%C3%A9enne_(logo).svg)  |
| **Warioland 4**  | high-resolution logo taken from [Mario Wiki](https://www.mariowiki.com/Gallery:Wario_Land_4#/media/File:Wl4-Logo_Artwork.png)  |
| **Green overlay**  | consists in a simple rectangle shape with a green color and an alpha value. The color and alpha value parameters are easily tweaked to change the green shade as needed  |
| **Background**  | I couldn't find a high-res version of the background so I painstakingly recreated it little by little using the artwork available from [Mario Wiki](https://www.mariowiki.com/File:WL4_Box_Artwork_Full_and_Text.png). At the time AI stuff didn't exist so maybe today you could have a cleaner result much faster  |

The "draft" folder contains the original Paint.NET (.pdn) file used to build the background. I wouldn't recommend opening it.

Of note: I made the label before I knew the final name of the patch was going to be Jungle Rumble!

I made a custom cartridge using the very best rumble GBA flashcart in the market by insideGadget: [GBA 32MB, 256Kbit FRAM Save, Flash Cart (Rumble optional)](https://shop.insidegadgets.com/product/gba-32mb-256kbit-fram-save-flash-cart/)
